The three-order model

One Convert to Sale action decomposes the loan into a return and a sale — both linked back to the original loan order, so the whole chain reads from one record. Numbers below are the live org chain.

How it's configured in Salesforce

Standard Order
3 custom record types — Loan / Return / Sale_Order. No OMS objects.
Custom fields
Original_Loan_Order__c (lineage) + Asset.Order__c (asset ↔ order).
SAP stub
SAP_Reconciliation__e platform event — 2 per asset (Return + Reissue). Publish-only, no live SAP.
Automation
Invocable Apex HAV_LoanToSaleService, all-or-nothing. Quick action → Convert_Loan_To_Sale flow.
Security & REST
HAV_Loan_To_Sale permission set. Also headless: POST /hav/loan-to-sale.

One transaction, five effects

1Creates Return + Sale orders, both linked to the loan
2Re-points the asset to the sale order
3Stamps Lease_Type=Sale, Converted to Sale
4Activates entitlements on the asset
5Publishes 2 SAP events — rolls back fully on any failure
