# Vignette 1 — The Order That Almost Didn't Close
**Duration:** 10 minutes | **Persona:** Sales coordinator

## Narrative Setup
> "A customer wants to convert a loaner Veloce system to a permanent sale. In the current process, this requires coordination between sales, legal, finance, logistics, and compliance — all via email. The deal stalls because nobody knows who has approved what. Let's see what that looks like when everyone's on the same platform."

## Click Path

### Step 1: Orders Pipeline (2 min)
**Navigate to:** `/orders`

**Talk track:**
- "Here's the full order pipeline — every sales agreement, loan, lease, and purchase order."
- Point to a **specific order** for a major customer (e.g., Arm Holdings or NVIDIA).
- "This order started as a loaner agreement. The customer wants to convert to a sale."
- Show the **Status badge** — highlight the stage it's in.
- "Today, this status would be tracked in a SharePoint list. Here, it's real-time."

### Step 2: Compliance Check (3 min)
**Navigate to:** `/orders/compliance`

**Talk track:**
- "Before any hardware crosses a border, five compliance checks must pass."
- Click to **expand** the order from Step 1.
- Walk through each check:
  1. **ECCN Classification** — "Is this controlled technology? Verified automatically."
  2. **Denied Party Screening** — "Customer cleared against all restricted party lists."
  3. **End-Use Verification** — "Confirmed compliant application."
  4. **Country Controls** — "Destination cleared for controlled hardware."
  5. **Export License** — "NLR confirmed or license obtained."
- "In the current process, these checks are emailed around individually. Here, it's a single audit trail."

### Step 3: Order Traveler (3 min)
**Navigate to:** `/orders/travelers`

**Talk track:**
- Find the same order — show the **workflow pipeline** visualization.
- "This is the traveler — the same document that currently lives in SharePoint and gets emailed between five teams."
- Walk through stages: Order Received → Export Compliance → Logistics Booked → Shipped → Goods Receipt → Install Verified.
- Point to the **current stage** (animated pulse indicator).
- "Every stakeholder can see exactly where the order stands. No more 'who has the traveler?' emails."
- Show the order details: order number, quantity, total value.

### Step 4: Agent Assist (2 min)
**Open:** Agent Chat

**Talk track:**
- Type or click: **"What's the status of the loan-to-sale for Arm Holdings?"**
- "The agent knows the order pipeline. It can tell you the status, the compliance state, and the next action — without navigating anywhere."

## Key Messages
- Five teams, one view — no email chains
- Compliance is automated and auditable
- The traveler is digital, tracked, and real-time
- Agent can answer order questions instantly
