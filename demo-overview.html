What This Demo Is

A working prototype that replaces the spreadsheets, SharePoint travelers, and email chains running EDA's HAV operations today with a single Salesforce-connected platform. It shows — with live data from the Salesforce org — how orders, capacity, finance, compliance, work orders, and asset management can operate from one data model, with an Agentforce AI agent that answers questions in natural language.

This is not a slide deck. Every screen in the demo is a live application connected to real Salesforce data. The goal is to make the transformation tangible — not theoretical.

Today's Reality

  • •Capacity planning lives in three Excel spreadsheets updated biweekly
  • •Order travelers are SharePoint documents emailed between five teams
  • •Quarter close takes two weeks to reconcile revenue vs. COGS in Excel
  • •Export compliance checks are manual, emailed individually
  • •Blade failures discovered when the customer calls

What the Demo Shows

  • •Capacity, power, and PUE in one real-time dashboard per facility
  • •Travelers are system-tracked workflows visible to all stakeholders
  • •Revenue, COGS, and BOM reconciliation in one always-current view
  • •Five compliance checks automated with audit trail
  • •Failures detected by live telemetry → auto work orders

How It's Built

Salesforce Org

  • Custom objects: Assets, Work Orders, Telemetry, Orders, Locations
  • 7 Apex REST APIs serving all data
  • 250+ demo records (real customer names, serial numbers, facilities)
  • Agentforce agent with natural-language access to all data

React Dashboard

  • 14 views: Dashboard, Assets, Capacity, Financials, Work Orders, Orders, Telemetry + 7 sub-views
  • Collapsible sidebar with auto-expanding sub-navigation
  • Recharts visualizations (bar, line, pie, Gantt timelines)
  • Embedded Tableau Next analytics

Hosting & Integration

  • Heroku deployment (Node.js + Express server)
  • GitHub CI/CD from afisher-salesforce/siemens-eda-hav-demo
  • Salesforce Connected App (OAuth 2.0 JWT)
  • Agentforce Agent API for AI-powered chat
